# Claude Code Instructions

## Commit Rules

You must follow the Conventional Commits rules, ensuring that the scope and module are included.

For example:

```md
fix(heartbeat): fix debounce timing issue
feat(config): add YAML config file support
refactor(socket): improve connection error handling
perf(collector): reduce memory allocation in event processing
docs(readme): update installation instructions
test(utils): add tests for SystemUtils
build(gradle): update IntelliJ Platform plugin version
ci(actions): add code coverage reporting
```

## Project Structure

This is a JetBrains IDE plugin written in Kotlin. Key components:

- `src/main/kotlin/xyz/shelltime/jetbrains/` - Main source code
- `src/main/resources/META-INF/plugin.xml` - Plugin manifest
- `src/test/kotlin/` - Unit tests
- `build.gradle.kts` - Gradle build configuration
- `gradle/libs.versions.toml` - Dependency version catalog

## Build Commands

```bash
# Build the plugin
./gradlew buildPlugin

# Run tests
./gradlew test

# Run IDE with plugin
./gradlew runIde

# Verify plugin compatibility
./gradlew verifyPlugin

# Generate coverage report
./gradlew koverHtmlReport
```

## Architecture Notes

1. **Services**:
   - `ShellTimeService` (App-level): Global config and socket client
   - `ShellTimeProjectService` (Project-level): Per-project heartbeat collection

2. **Heartbeat Flow**:
   - IDE events → `HeartbeatCollector` → `HeartbeatSender` → `SocketClient` → Daemon

3. **Configuration**:
   - File config: `~/.shelltime/config.toml` (TOML or YAML)
   - IDE settings: Tools → ShellTime

## Testing

- Unit tests use JUnit 5 and MockK
- Coverage reports generated by Kover
- Integration tests use IntelliJ test framework
